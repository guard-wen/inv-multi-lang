# Manual image slots

Add the final instruction-manual images here using these exact file names:

- `150w-en.jpg` — English
- `150w-zh-CN.jpg` — Simplified Chinese
- `150w-zh-TW.jpg` — Traditional Chinese
- `150w-de.jpg` — German
- `150w-es.jpg` — Spanish

Recommended width: at least 1200 px. Keep the image text legible and compress it for web delivery.
